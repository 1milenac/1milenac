About

I build scalable geospatial systems for Earth observation, from raw satellite imagery to production APIs.

My work combines optical and SAR remote sensing, machine learning and cloud engineering to monitor environmental change across large areas and long time periods.

I design cloud-native pipelines on Google Cloud and Google Earth Engine using analysis-ready formats such as Cloud Optimized GeoTIFF, Zarr and STAC catalogues, and parallelise processing with Dask and xarray.

Results are served through FastAPI services, React interfaces and Streamlit dashboards, containerised with Docker and deployed on Cloud Run.

How I build

  1. Ingest

    Query STAC catalogues and Earth Engine collections, and store imagery as Cloud Optimized GeoTIFF and Zarr in Cloud Storage.

  2. Process

    Parallel preprocessing, including SAR calibration and speckle filtering, plus compositing and feature extraction with Dask, xarray and Earth Engine, run as containerised jobs.

  3. Model

    Train and validate classifiers with scikit-learn, XGBoost and PyTorch, with accuracy tracked per region and year.

  4. Serve

    Expose outputs through FastAPI and BigQuery, and explore them in React and Streamlit apps on Cloud Run.

What I work on

  • Remote sensing

    Multi-sensor optical and SAR time series, machine learning land cover classification and change detection at regional to national scale.

  • Environmental monitoring

    Automated, repeatable monitoring of vegetation, land cover and land use that updates as new imagery arrives.

  • Geospatial engineering

    Cloud-native, containerised pipelines on Google Cloud for large raster and vector data, with parallel processing and analysis-ready outputs.

  • Spatial data science

    Machine learning, model evaluation and uncertainty, and clear visualisation of spatial and temporal patterns.
